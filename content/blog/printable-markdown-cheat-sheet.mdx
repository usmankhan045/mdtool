## What syntax is on the printable Markdown cheat sheet?

Everything you need for READMEs, docs, notes and issue comments. Base syntax follows the [CommonMark spec](https://spec.commonmark.org/); items marked GFM come from the [GitHub Flavored Markdown spec](https://github.github.com/gfm/); items marked GitHub are GitHub-specific features from [GitHub's writing docs](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax).

| Element | Syntax | Where it works |
|---------|--------|----------------|
| Headings 1 to 6 | `# H1` to `###### H6` | Everywhere |
| Bold | `**bold**` | Everywhere |
| Italic | `*italic*` or `_italic_` | Everywhere |
| Bold and italic | `***both***` | Everywhere |
| Strikethrough | `~~deleted~~` | GFM |
| Inline code | `` `code` `` | Everywhere |
| Paragraph | Blank line between blocks | Everywhere |
| Line break | Two trailing spaces, or `<br>` | Everywhere |
| Escape a symbol | `\*not italic\*` | Everywhere |
| Hidden comment | `<!-- not rendered -->` | Everywhere |
| Bulleted list | `- item` | Everywhere |
| Numbered list | `1. item` | Everywhere |
| Task list | `- [ ] to do` / `- [x] done` | GFM |
| Link | `[text](https://example.com "title")` | Everywhere |
| Reference link | `[text][id]` + `[id]: https://example.com` | Everywhere |
| Autolink | `<https://example.com>` | Everywhere |
| Heading link | `[Jump](#heading-text)` | GitHub and most renderers |
| Image | `![alt text](image.png)` | Everywhere |
| Blockquote | `> quote` | Everywhere |
| Horizontal rule | `---` | Everywhere |
| Fenced code block | ` ```python ` … ` ``` ` | Everywhere |
| Table | `\| A \| B \|` + `\|---\|---\|` | GFM |
| Table alignment | `:---` left, `:---:` center, `---:` right | GFM |
| Footnote | `Text[^1]` + `[^1]: The note` | GitHub, not every renderer |
| Alert | `> [!NOTE]`, also TIP, IMPORTANT, WARNING, CAUTION | GitHub |
| Diagram | ` ```mermaid ` fence | GitHub, MDTool |

"Everywhere" means any CommonMark-compliant renderer. Footnotes and alerts are the ones that most often fail outside GitHub, so test them in your target tool before you rely on them.

`````markdown
# Markdown Cheat Sheet

Compact reference for CommonMark and GitHub Flavored Markdown (GFM). Free from mdtool.dev.

| Element | Syntax |

## Code blocks

Fence with three backticks and add a language for syntax highlighting:

````
```python
def hello():
    print("Hello, Markdown")
```
````

Use a `mermaid` language tag to draw a diagram on GitHub and in MDTool.

## Tables (GFM)

```
| Left   | Center | Right |
|:-------|:------:|------:|
| a      |   b    |     c |
```

Colons in the separator row set alignment. Escape a pipe inside a cell as `\|`.
`````

The source uses four backticks around the code example so the inner three-backtick fence displays as text instead of being treated as the end of the block. Keep that when you edit it.
