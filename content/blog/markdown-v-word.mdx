Чтобы перевести Markdown в Word, откройте [конвертер Markdown в Word](/markdown-to-word), вставьте текст или загрузите `.md`-файл и нажмите **Download Word (Free)**. Получится настоящий `.docx`: заголовки `#` превращаются в стили «Заголовок 1»–«Заголовок 6», таблицы и списки остаются редактируемыми. Всё работает в браузере, без регистрации.

Задача возникает постоянно. Вы пишете документацию, README или заметки в Markdown, а коллеги, заказчик или научный руководитель ждут файл Word, чтобы оставить правки в режиме рецензирования. Копировать отрендеренный текст из браузера в Word можно, но тогда заголовки становятся просто крупным жирным текстом, а не стилями, и оглавление собрать уже не получится.

## Как конвертировать .md в .docx: пошагово

Интерфейс MDTool на английском, но в нём всего одно поле ввода и одна кнопка скачивания, так что разобраться можно за минуту.

1. Откройте [конвертер Markdown в Word](/markdown-to-word).
2. Вставьте текст в левое поле **Markdown Input** или нажмите **Upload .md** и выберите файл. Подходят расширения `.md`, `.markdown` и `.txt`, файл можно и просто перетащить в поле.
3. Справа появится предпросмотр. Он примерно показывает, как документ будет выглядеть в Word.
4. Нажмите **Download Word (Free)**. Браузер сохранит файл `document.docx`.
5. Откройте файл в Word. Если сверху появится жёлтая плашка «Защищённый просмотр», нажмите **Разрешить редактирование**: Word так реагирует на любые файлы, скачанные из интернета.
6. Проверьте структуру: **Вид → Область навигации** или Ctrl+F. Все заголовки из Markdown должны появиться в списке слева.

Файл никуда не загружается. Документ собирается прямо в браузере, поэтому конвертер подходит и для текстов, которые нельзя отправлять на сторонние серверы. Сервис бесплатный, без регистрации и без водяных знаков.

## Что сохраняется при конвертации?

Конвертер строит `.docx` из структуры Markdown, а не из скриншота или HTML-обёртки. Поэтому файл корректно открывается не только в Word, но и в Google Документах и LibreOffice.

| Markdown | Результат в Word | Комментарий |
|---|---|---|
| `#` … `######` | стили «Заголовок 1» … «Заголовок 6» | видны в области навигации и в оглавлении |
| `**жирный**`, `*курсив*` | жирное и курсивное начертание | |
| `~~зачёркнутый~~` | зачёркнутый текст | |
| `` `код` `` | шрифт Courier New | |
| блок кода в ` ``` ` | Courier New на сером фоне | без подсветки синтаксиса |
| `-` и `1.` | маркированный и нумерованный список | нативные списки Word, вложенные уровни сохраняются |
| таблица | таблица Word с жирной шапкой | шапка повторяется на каждой странице |
| `[текст](https://…)` | кликабельная гиперссылка | |
| `> цитата` | курсив с отступом и линией слева | |
| картинки, диаграммы Mermaid | не переносятся | см. ниже |

Обратите внимание на таблицы: первая строка автоматически помечается как строка заголовка. Если таблица длинная и переходит на следующую страницу, шапка повторится сверху. В Word это та же настройка, что и **Макет таблицы → Данные → Повторять строки заголовков**, описанная в [справке Microsoft о повторении заголовка таблицы](https://support.microsoft.com/ru-ru/office/2ff677e0-3150-464a-a283-fa52794b4b41). Синтаксис таблиц в Markdown собран в [шпаргалке по таблицам](/markdown-cheat-sheet/tables) (на английском).

## Почему важны настоящие стили заголовков?

Стиль заголовка в Word — это не внешний вид, а разметка структуры. Именно на неё опираются несколько функций Word:

- **Область навигации.** Как сказано в [справке Microsoft об области навигации](https://support.microsoft.com/ru-ru/word/use-the-navigation-pane-in-word), там отображаются только заголовки, к которым применены стили заголовков. По ним можно переходить по документу и перетаскивать целые разделы.
- **Автоматическое оглавление.** Поставьте курсор в начало документа и выберите **Ссылки → Оглавление**. Word соберёт его из стилей «Заголовок 1», «Заголовок 2» и «Заголовок 3», как описано в инструкции [«Вставка оглавления»](https://support.microsoft.com/ru-ru/office/%D0%B2%D1%81%D1%82%D0%B0%D0%B2%D0%BA%D0%B0-%D0%BE%D0%B3%D0%BB%D0%B0%D0%B2%D0%BB%D0%B5%D0%BD%D0%B8%D1%8F-882e8564-0edb-435e-84b5-1d8552ccf0c0).
- **Оформление в один клик.** Чтобы поменять шрифт или отступы у всех заголовков сразу, на вкладке **Главная** в группе **Стили** щёлкните правой кнопкой по «Заголовок 1» и выберите **Изменить**. Изменения применятся ко всем заголовкам этого уровня.

Поэтому в исходном Markdown стоит соблюдать иерархию: один `#` для названия документа, `##` для разделов, `###` для подразделов, без пропуска уровней. Подробнее о синтаксисе заголовков — в [шпаргалке по заголовкам](/markdown-cheat-sheet/headings).

## Какие есть ограничения?

Честно о том, что конвертер пока не умеет:

- **Картинки** не попадают в `.docx`. Вставьте их в Word вручную через **Вставка → Рисунки**.
- **Диаграммы Mermaid** тоже не экспортируются в Word. Если они важны, используйте [конвертер Markdown в PDF](/markdown-to-pdf): там диаграммы рендерятся в готовые изображения, а код подсвечивается.
- **Подсветка синтаксиса** в блоках кода не сохраняется, код остаётся моноширинным на сером фоне.

Практический совет: перед экспортом пробегитесь по исходнику глазами. Уберите ссылки на картинки, которые всё равно придётся вставлять вручную, и проверьте, что у каждой таблицы есть строка-шапка с разделителем `|---|`. Тогда документ в Word почти не потребует правок.

## Когда лучше использовать pandoc?

Если вы конвертируете много файлов, вам нужны картинки или собственный корпоративный шаблон, удобнее консольная утилита [pandoc](https://pandoc.org/MANUAL.html). Базовая команда:

```bash
pandoc заметки.md -o заметки.docx
```

Чтобы документ сразу получил ваше оформление, выгрузите шаблон pandoc, настройте в нём стили в Word и укажите его при конвертации:

```bash
pandoc -o шаблон.docx --print-default-data-file reference.docx
pandoc заметки.md --reference-doc=шаблон.docx -o заметки.docx
```

| Критерий | MDTool | pandoc |
|---|---|---|
| Установка | не нужна | нужно установить |
| Интерфейс | браузер, предпросмотр в реальном времени | командная строка |
| Стили заголовков Word | да | да |
| Картинки | нет | да |
| Свой шаблон оформления | нет | да, через `--reference-doc` |
| Пакетная обработка | по одному файлу | да, через скрипт |

Для одного документа, который нужно отправить прямо сейчас, браузерный конвертер быстрее. Для регулярной сборки документации из репозитория лучше подходит pandoc.

Нужно обратное направление? [Конвертер Word в Markdown](/word-to-markdown) превращает `.docx` обратно в Markdown: стили «Заголовок 1–6» становятся `#`–`######`, таблицы с шапкой — Markdown-таблицами.

## Часто задаваемые вопросы

**В: Это бесплатно? Будет ли водяной знак?**

Да, конвертер полностью бесплатный, регистрация не нужна, водяных знаков и ограничений по количеству файлов нет.

**В: Загружается ли мой файл на сервер?**

Нет. Документ создаётся прямо в браузере, текст не покидает ваш компьютер. Это удобно для внутренних и конфиденциальных документов.

**В: Почему в Word не появились картинки и диаграммы?**

Экспорт в Word пока не переносит изображения и диаграммы Mermaid. Вставьте картинки в Word вручную или используйте экспорт в PDF, где Mermaid-диаграммы отображаются.

**В: Откроется ли файл в Google Документах и LibreOffice?**

Да. Это стандартный `.docx`, собранный из структуры документа, поэтому его корректно открывают Word, Google Документы и LibreOffice Writer.

**В: Интерфейс на английском — это проблема?**

Нет. Вам нужны только поле **Markdown Input**, кнопка **Upload .md** и кнопка **Download Word (Free)**. Сам документ и стили в Word будут на языке вашей версии Office, например «Заголовок 1».
